# Ngoc Nguyen — UI/UX Designer Portfolio

A modern, responsive, and performance-optimized personal portfolio showcasing UI/UX design case studies, web and mobile application prototypes, design systems, and creative projects.

## 🚀 Features

- **Responsive Design**: Fluid layout adapting seamlessly across desktop, tablet, and mobile screens.
- **Interactive Lightbox Modal**: High-resolution case study detail viewer with backdrop blur and smooth scrolling.
- **Custom Cursor & Smooth Micro-interactions**: Editorial typography in Gilroy, spring physics, and subtle hover animations.
- **Pure Web Technologies**: Vanilla HTML5, modern CSS3 (Custom Properties & Flex/Grid), and vanilla JavaScript.

## 📁 Project Structure

```
├── index.html          # Main portfolio homepage
├── projects.html       # Full projects archive page
├── index.css           # Design tokens, typography system, and components
├── app.js              # Interactions, modal lightbox, and smooth reveal logic
├── assets/             # Project thumbnails, high-resolution case studies, and media
└── .gitignore          # Git ignore file
```

## 🛠️ Local Development

To view the website locally, you can use any local web server:

```bash
# Using Python 3 built-in HTTP server:
python3 -m http.server 3000
```

Then open your browser and navigate to `http://localhost:3000`.
